#### Public Support for State Secession
Survey Research · Public Opinion · Quantitative Analysis

Research examining Americans' attitudes toward state secession using data from the Cooperative Election Study. We find little evidence that partisan motives drive support for state secession. Instead, support is more closely associated with opposition to a strong central government. While most Americans reject proposals to fragment the union, those who oppose secession tend to be motivated by strong national attachments and commitments to the rule of law.
